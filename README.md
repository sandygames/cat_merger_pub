# Cat Merge

Drop · merge · don’t hit the line

Cat Merge is a free puzzle for iPhone and iPad. Drop cartoon cats into the well, merge two of the same kind, and chase combos — just don’t let the stack reach the line.

No account. Play offline. Optionally join the world leaderboard with a nickname. A small banner supports the game; Remove Ads is a one-time in-app purchase.
